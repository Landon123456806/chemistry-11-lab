### Chemical Concept

The decomposition of hydrogen peroxide is a classic example of:
- **Exothermic reaction** (releases heat)
- **Catalyzed reaction** (yeast/catalase enzyme speeds it up)
- **Decomposition reaction** (one reactant breaks into two products)

**Reaction Equation:**
```
2 H₂O₂ --[catalase]--> 2 H₂O + O₂↑
```
